# My Archive — прототип библиотеки историй

Статический прототип главной: бренд, твоё описание, лента историй и поиск.
Сейчас это не WordPress-тема, а отдельная HTML/CSS/JS-страница. Контент можно позже подтянуть с WordPress или перенести сайт целиком.

## Что внутри

- `index.html` — главная
- `style.css` — визуал
- `stories-data.js` — демо-данные с [wolf574.wordpress.com](https://wolf574.wordpress.com/)
- `script.js` — поиск по ленте

## Локально

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```
