# My Archive — прототип библиотеки историй

Чистая структура архива рассказов по мотивам большой гей-библиотеки: лента, метки, поиск, случайный рассказ — без знакомств, объявлений и прочего мусора в шапке.

## Что внутри

- `index.html` — главная: бренд, архив, боковые метки
- `style.css` — тёмный «архивный» визуал
- `stories-data.js` — демо-данные с реальных заголовков [wolf574.wordpress.com](https://wolf574.wordpress.com/)
- `script.js` — фильтры, поиск, случайная история

## Локально

Открой `index.html` или подними статику:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

## Дальше

Можно подключить WordPress REST / RSS или Supabase вместо статичного `stories-data.js` и добавить страницу чтения.
